# Local game library

This directory is intentionally kept out of Git.

Place only game files you are legally entitled to use in the appropriate system directory. Suggested layout:

```text
roms/
├── arcade/
├── dos/
├── gba/
├── gbc/
├── gb/
├── genesis/
├── n64/
├── nes/
├── psx/
├── psp/
└── snes/
```

The exact directory names used by the final RomM configuration will be kept aligned with its platform mapping.

Do not commit commercial ROMs, BIOS files, or other copyrighted game assets to this repository.
